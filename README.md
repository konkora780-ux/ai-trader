# AIトレーダー（段階1：分析・LINE通知）

日本株の値動きを毎日チェックし、売買サインが出たらLINEに知らせます。
結果はスマホでも見られる画面（`docs/index.html`）にまとめます。
**この段階では注文は一切しません。**

## できること
- `config.yaml` を書き換えるだけで、銘柄・ルール・数字を変えられます。
- ルールごとに「過去3年でこのルールを使っていたら、損益はどうだったか」（試運転）を表示します。
  1株単位・予算10万円で計算するので、プチ株のような少額売買のイメージです。

## 入っているルール
| 名前 | 中身 |
|---|---|
| golden_cross | 5日平均が25日平均を上に抜けたら買い、下に抜けたら売り |
| rsi | RSI（上がり下がりの勢いを0〜100で表す数値）が30を下回ったら買い、70を上回ったら売り |
| bollinger | 価格が普段の値動きの幅より大きく下がったら買い、平均に戻ったら売り |

## 動かし方A：GitHubで毎日自動（おすすめ）
PCを切っていても、平日16:00に自動で動き、スマホで結果を見られます。
1. GitHubで新しいリポジトリ（保存場所）を作り、このフォルダの中身をアップロードします。
2. LINEの鍵を登録します：リポジトリの Settings → Secrets and variables → Actions →
   New repository secret で、名前 `LINE_CHANNEL_ACCESS_TOKEN`、値に下の手順で取った鍵を入れます。
3. 結果画面の公開：Settings → Pages → Branch を `main`、フォルダを `/docs` にして保存します。
   表示されるURLをスマホのホーム画面に追加しておくと便利です。
4. Actions タブ → daily-signal → Run workflow で、すぐに試せます。

> 注意：無料のGitHubでは、結果画面（Pages）を使うにはリポジトリを公開にする必要があります。
> 見ている銘柄が他人にも見える点だけご了承ください。

## 動かし方B：Windows PCで手動
1. Python（https://www.python.org/）をインストールします（インストール時に「Add python.exe to PATH」にチェック）。
2. `run.bat` をダブルクリックすると、分析して結果画面が開きます。
3. LINEにも送る場合は、環境変数 `LINE_CHANNEL_ACCESS_TOKEN` に鍵を設定します。

## LINEの鍵の取り方（LINE Messaging API）
LINE Notify は2025年3月に終了したため、LINE公式アカウントを使います。
1. https://developers.line.biz/ にLINEアカウントでログインし、プロバイダーを作成します。
2. 「Messaging API」チャネルを作成します（LINE公式アカウントが作られます）。
3. チャネルの「Messaging API設定」で、QRコードから自分のLINEで友だち追加します。
4. 同じ画面の一番下「チャネルアクセストークン（長期）」を発行し、その文字列が「鍵」です。
- 無料プランは月200通まで。1日1通なので十分です。
- 鍵はパスワードと同じです。人に見せたり、ファイルに書いてアップロードしたりしないでください。

## 動作確認だけしたいとき
`py main.py --sample` で、架空の株価を使って画面と通知文を確認できます。

## 確認が必要な点
- 株価は Yahoo!ファイナンス（米国版）のデータを `yfinance` という非公式ツールで取っています。
  個人の分析用途では広く使われていますが、公式サービスではないため、仕様変更で止まることがあります。
  その場合は日本取引所の公式データ「J-Quants」への切り替えを検討します。

## 段階2：仮想売買（本物のお金は使いません）
- 毎日のサインどおりに、仮想資金100万円で売買したことにして記録します（`docs/paper.json`）。
- サインが出た翌営業日の始値（寄付）で約定したことにします。手数料などとして片道0.1%を引きます。
- 1銘柄あたり最大20万円（資金÷5銘柄）、買値から10%下がったら損切りします（`config.yaml` の `paper` で変更可）。
- 成績は結果画面の一番上と、売買があった日のLINEで確認できます。比べる相手は「市場全体（TOPIX連動ETF 1306）をずっと持っていたら」です。
- 最初からやり直したいときは `docs/paper.json` を消します。
